# Makeover · AI Interior Studio

Upload a photo of a room, pick the room type and a style, choose what to keep, and get a photorealistic redesign from Google Gemini. Compare before and after with a slider, download the result, and save designs in the browser.

Built by Group 36, Outskill AI Accelerator.

## Run it

Open `index.html` in Chrome or Edge. No build step.

## Gemini API key

Image generation needs a Gemini API key with billing enabled (the free tier has no image quota).
Get one at https://aistudio.google.com/apikey and paste it into the **Gemini API key** field in the studio.
The key is stored only in your own browser and is never written into the code.
